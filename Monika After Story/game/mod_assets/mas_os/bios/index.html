Игра

Python и MAS OS стартуют отсюда. Сессия Моники ещё не началась.

Файлы

Системный пикер кладёт файл сразу в characters, custom_bgm, chess_games или _mas/archives.

Архивы DDLC

Картинки и музыка не внутри APK. Официальный zip — с ddlc.moe. GitHub остаётся запасным источником.

Контент

Один zip — BIOS сам поймёт: сабмод, спрайтпак или рескин. Ссылка запоминается, чтобы не искать снова.

Недавние ссылки

Библиотека

Все поставленные паки в одном месте. Снятие одного не трогает остальные.

Пак тип файлов

Сейвы

Можно указать zip или уже распакованную папку с другой сборки. BIOS разложит persistent, слоты, characters.

Обновление APK

GitHub Release порта. Установщик Android, не загрузка внутри Ren'Py.

Движок шахмат

Запуск идёт из libstockfish.so в nativeLibraryDir APK. Android 10 блокирует exec из files/, поэтому копировать ELF туда бесполезно. UCI здесь те же команды, что шлёт Ren'Py. Если BIOS отвечает, а игра нет — копать Python.

Рекавери Моники

Если файл monika пропал из characters/, BIOS ищет его в Documents и возвращает на место. Пустой стол в игре ждёт этот файл.

Система

Флаги старта, traceback и запасной xml.

Ещё

Архивы DDLC, движок шахмат, рекавери, файлы и система.

Нужен доступ к файлам

      
MAS пишет всё в Documents/Monika_after_story: сейвы, подарки, музыку, игру. Архивы и логи — в _mas/.

      
Без разрешения Android 11+ эта папка закрыта. Тогда архив не встанет, сейвы пропадут при удалении приложения, а игра не увидит картинки.

      
Нажми кнопку, включи «Доступ ко всем файлам» для MAS и вернись сюда. BIOS сам проверит диск.
