# Эскизы оболочек BIOS

Это **не** часть APK и не копируется `sync_mas_bios.py`.

Все виды одним списком: открой **`nav.html`** в браузере (фильтры: идеальный / оболочки / загрузки / метафоры / старое).

Рекомендуемый макет: **`rail-ideal.html`** — категории слева (сворачиваются в иконки), плитки в центре, журнал справа, очередь загрузок, настройки (тема и «сразу MAS»).

Вариант без подкатегорий: **`rail-tall.html`** — одна высокая главная плитка, справа стопка горизонтальных.

**`rail-ideal3.html`** — несколько главных плиток в сетке, внутри статус/прогресс, без пустой колонны.

Метафоры отдельно: **`fresh.html`**.
Одинаковое дерево в `tree.js`: Игра / Контент / Данные / Система.

- `rail-list.html` — все подкатегории строками (нравится, не менять)
- `rail-tiles.html` — чипы + плитки, Play на рейке (нравится, не менять)
- `rail-modal.html` — карточки открывают модальное окно
- `rail-sheet.html` — список, действия нижним листом
- `rail-split.html` — мастер-деталь, на телефоне страница с «назад»
- `rail-stack.html` — одна подкатегория, крупный primary, диалог для опасных

Новые оболочки (Список/Плитки не трогали):

- `rail-gear.html` — split-кнопка + ⚙ меню (безопасный вход и т.д.), пункт «Качать»
- `rail-plus.html` — плитки с ⚙ в углу и на Play, лист загрузок сверху

Менеджер загрузок (`packs.js`: images.rpa, audio, zip, паки, APK):

- `dl-cod.html` — как COD / Delta Force Mobile: табы, бар на каждом паке, скачано/нет
- `dl-delta.html` — Download Center: база залочена, галочки, SD/HD, «Установить»
- `dl-queue.html` — один активный файл, очередь, пауза всем
- `dl-cards.html` — круговой прогресс на карточках

Старые клоны Windows/Gnome/Mac/консолей: `index.html`.

В саму игру вшит только вид **MASL** (Пуск / рабочий стол) — переключается кнопкой «вид» в живом BIOS: классика → остров → колода → MASL.

MASL срисован с [Traduction Club MASL](https://github.com/New-Traduction-Club/MonikaAfterStory-Android-port) автора Just: виртуальный Windows-десктоп, кнопка Пуск, список слева, «Все программы» второй колонкой, трей с часами, окна поверх обоев.
