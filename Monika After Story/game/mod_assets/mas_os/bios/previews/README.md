# Эскизы оболочек BIOS

Это **не** часть APK и не копируется `sync_mas_bios.py`. Открой `index.html` в браузере телефона или ПК.

В саму игру вшит только вид **MASL** (Пуск / рабочий стол) — переключается кнопкой «вид» в живом BIOS: классика → остров → колода → MASL.

MASL срисован с [Traduction Club MASL](https://github.com/New-Traduction-Club/MonikaAfterStory-Android-port) автора Just: виртуальный Windows-десктоп, кнопка Пуск, список слева, «Все программы» второй колонкой, трей с часами, окна поверх обоев.
