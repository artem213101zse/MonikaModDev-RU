Свежие шаблоны

Не Windows и не колода. Открой любой файл в браузере телефона. Кнопки пишут в журнал, Java нет — это только вид.

ZineЖурнал литклуба. Крупная вёрстка, вертикальный скролл, одна тема — одна полоса.
ОрбитаПуск в центре, разделы как спутники. Палец по кругу, лист снизу.
КассетаБольшая кнопка Play, остальное — дорожки микстейпа. Индикаторы загрузки как VU.
ТаблоТабло вылета. Каждая строка — раздел BIOS, статус справа.
ПисьмаСтопка конвертов от Моники. Листаешь письма, внутри действия.
VHSКамера и кассеты. REC, таймкод, главы вместо меню.
ПалитраПустой экран и поиск. Всё — крупные строки. Самый быстрый для одной руки.
МаркиПробковая доска и кривые Polaroid. Разный размер карточек, не сетка 2×N.

Все виды одним списком: nav.html · идеальный: rail-ideal.html · клоны ОС: index.html
